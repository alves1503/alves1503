## Sobre

Desenvolvedor de Software e estudante de **Análise e Desenvolvimento de Sistemas na PUC Minas**, com atuação em **TI corporativa** na Lider Interiores.

Construo **aplicações web full stack, APIs REST e integrações**, e uso **IA generativa** (RAG, embeddings e agentes) para automatizar processos e criar atendimento inteligente. Meu foco é backend e engenharia de software, com **Java, Spring Boot e arquitetura de software**, sempre com atenção a código limpo, organização e entrega de valor real.
